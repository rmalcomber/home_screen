# Contributing to Home Screen

Contributions are welcome. Full guidance is on the docs site: https://rmalcomber.github.io/home_screen/project/contributing/

- Home Screen has a size budget (binary and first page load). Open an issue before anything larger than a fix.
- Run `cargo test`, then `npm test` and `npm run audit:css` in `web/`, before opening a pull request.
- Branch from `main`, open the pull request against `main`, keep it focused, add tests and update the docs.
