## Settings

- **Upload images** (PNG, JPEG, GIF, WebP, AVIF), or paste image **URLs**, one per line. Uploaded images are stored in the database.
- **Seconds per image**: `0` means manual only.
- **Fit**: *Fill (crop)* or *Fit (whole image)*.

Slides advance automatically and pause while you hover. Arrows and dots appear on hover.
