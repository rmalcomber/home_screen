## Building

A clean `cargo build --release` (compiling every dependency) takes about **{{metric.build_time}}**.

## How these were measured

- **Machine**: {{metric.machine}}.
- **Size** is the release executable produced by `build.ps1`. "Compressed" is the same file gzipped at level 9.
- **Start-up** starts the executable with an empty database and counts the time until `/api/tiles` first answers.
- **Memory** is the process working set, read two seconds after forty requests.
- **Build time** is a clean build into an empty target directory.
- Your numbers will differ with your hardware; the file sizes will not.
