| Keys | Where | Action |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>P</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd> | Dashboard | Open or close the launcher |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | Dashboard | Open the launcher in command mode (`>`) |
| <kbd>/</kbd> | Dashboard | Focus the tile search box |
| <kbd>Esc</kbd> | Search box, launcher | Clear and leave, or close |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>PageUp</kbd> <kbd>PageDown</kbd> | Launcher | Move through results |
| <kbd>Enter</kbd> | Launcher | Open in a new tab, or copy the result |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Launcher | Open in the same tab |
| <kbd>Enter</kbd> | Curl, JSON, JWT and colour panels | Run, copy, copy payload, copy HEX |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Regex, diff, CSV, QR, Markdown, cron panels | Copy the main result |
| <kbd>n</kbd> <kbd>j</kbd> <kbd>k</kbd> <kbd>x</kbd> <kbd>e</kbd> <kbd>d</kbd> <kbd>c</kbd> <kbd>?</kbd>, <kbd>Shift</kbd>+<kbd>↑↓</kbd> | Todo widget | See [Todo list](/widgets/todo/) |

:::note[In widgets]
Inside a tool widget the shortcuts only apply while focus is inside that widget, and they use <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, so plain <kbd>Enter</kbd> stays free for typing.
:::

On Chrome, <kbd>Ctrl</kbd>+<kbd>P</kbd> normally opens the print dialog. Home Screen overrides it while the page has focus; click into the page first if the print dialog appears.
