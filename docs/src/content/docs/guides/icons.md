Tiles can have an optional icon next to the title. In the tile editor you can:

- **Search** by name (`github`, `aws`, `jira`, `terminal`). Icons come from the [Iconify](https://iconify.design) service, which includes Font Awesome (including all the brand icons), Simple Icons, Material and coloured logos. Nothing is bundled: icons are fetched when used.
- **Paste a name** such as `fa6-brands:github`.
- **Upload your own SVG.** It is cleaned (scripts and event handlers removed) and stored in the database. Your uploads are listed for reuse.

Link favicons in bookmark tiles are fetched from Google's favicon service for each site.

:::note
Searching for icons and showing them needs internet access, because icons are not bundled with the program. Uploaded SVGs are served from your own database and need no network.
:::
