**A lighter first load.** The widgets and launcher tools are now separate extensions, and the browser fetches each one only when it is needed. Nothing changes in how Home Screen looks or works, and your data is untouched.

[View this release on GitHub]({{releases}}/tag/v0.2.2-beta)

## What changed

- **Less to download on every page.** The script every page loads shrank from 321 KB to 113 KB (110 KB to 39 KB gzipped). A dashboard of bookmarks and notes no longer downloads the cron parser, the QR encoder or the Markdown tokenizer.
- **Extensions.** Each of the {{metric.widgets}} widgets and {{metric.tools}} launcher tools lives in its own folder with a manifest, an entry and an engine of pure functions. Adding one is a matter of adding a folder: [Extending Home Screen](/reference/extending/).
- **More tests.** {{metric.web_tests}} web tests (up from 208) now also check every manifest, the loading, and the rules for what an extension may import.

## Things you might notice

- **A brief "Loading…"** on a widget the first time it appears on a page, and the launcher fetches its tools when you open it. All of it is served from the program itself, so it is quick, and it works offline.
- **The program is about 19 KB larger** ({{metric.exe_bytes_fmt}} bytes) because many small files compress a little worse than one big one. It still fits on a floppy disk with room to spare: [Binary size](/reference/binary-size/).
- If a tab stays open across an upgrade, a widget may say it couldn't load. Reloading the page fixes it.

## Upgrading

Nothing to do. The database file format is unchanged, so an existing `home_screen.db` opens as before. Saved tiles, templates and the launcher's Recent list keep working.
