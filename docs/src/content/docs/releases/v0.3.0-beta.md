**Ten new tools, all in the launcher and as dashboard widgets.** Each is its own extension, so the first page load stays light: the browser fetches a tool only when it is used.

[View this release on GitHub]({{releases}}/tag/v0.3.0-beta)

## What's new

- **[URL and HTML](/launcher/url/):** encode, decode and take apart URLs and query strings, and HTML entities.
- **[JSON, YAML and TOML](/launcher/yaml/):** convert between the three formats. The parsers are small and cover config-style files; unsupported features are refused with a clear message.
- **[Number bases](/launcher/bases/):** hex, binary, octal and decimal, byte sizes (SI and IEC), and bit flags.
- **[IP and CIDR](/launcher/cidr/):** network, broadcast, masks and host ranges, membership and overlap checks, for IPv4 and IPv6.
- **[chmod and umask](/launcher/chmod/):** octal and symbolic permissions, with a clickable grid.
- **[Text case and counts](/launcher/text-case/):** every case spelling at once, slugs, and word, character and line counts.
- **[HTTP reference](/launcher/http-reference/):** status codes, headers and MIME types, built in and offline.
- **[Open Graph viewer](/launcher/open-graph/):** see how a link looks when shared, with every tag and a list of checks.
- **[Web search](/launcher/web-search/):** `google`, `ddg`, `github`, `mdn` and about twenty more engines.
- **[Can I use](/launcher/caniuse/):** browser support for a web feature.
- A new **Web & network** category in the widget gallery.
- {{metric.web_tests}} web tests (up from 225).

## Things you might notice

- **Open Graph** fetches pages through your Home Screen server, only when you press Enter or Fetch. **Can I use** downloads the public data (about 450 KB) from GitHub the first time you search, then keeps it in the browser for a week. Both are described in [Privacy and security](/guides/privacy-and-security/).
- The program is about 46 KB larger ({{metric.exe_bytes_fmt}} bytes) and still fits on a floppy disk with room to spare: [Binary size](/reference/binary-size/).

## Upgrading

Nothing to do. The database file format is unchanged.
