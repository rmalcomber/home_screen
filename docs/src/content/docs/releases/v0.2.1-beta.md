**A much smaller program.** The 64-bit Windows executable went from 2.36 MB to about 1.06 MB, small enough for a 1.44 MB floppy disk. The interface and your data are unchanged.

[View this release on GitHub]({{releases}}/tag/v0.2.1-beta)

## What changed

- **Smaller executable.** SQLite is built without the features Home Screen never uses, the web interface is embedded already gzipped, and the web server and the curl runner's HTTP client are now small hand-written ones instead of large libraries. The full story, with numbers: [Binary size](/reference/binary-size/).
- **Fewer styles to download.** Unused daisyUI components are left out of the CSS.
- **Tests for the new code.** The server and the HTTP client are covered by tests over real sockets.

## Things you might notice

- **Plain `curl` gets a `406`** from `http://localhost:7878/`, because the web files are stored gzipped. Browsers are unaffected, and `curl --compressed` works.
- **The curl runner** needs host names with non-ASCII characters written in their `xn--` form, has no HTTP proxy support, and does not forward `Authorization` or `Cookie` headers to a different site when it follows a redirect.
- **Stricter server limits.** Uploads and request bodies are capped at 8 MiB, chunked uploads are refused, and at most 64 connections are served at once. Normal browser use is not affected.

## Upgrading

Nothing to do. The database file format is unchanged, so an existing `home_screen.db` opens as before. Docker users can pull the new image as usual.
