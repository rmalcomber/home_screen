**A way to keep your links tidy, network tools that run the same everywhere, and files you can open instead of paste.**

[View this release on GitHub]({{releases}}/tag/v0.4.0-beta)

## What's new

- **[Clean up links](/guides/clean-up/):** find duplicates across every page, check which links are dead or moved, and tidy addresses. Nothing changes until you tick rows and press Apply, and you can undo. Open it from **☰**, **Settings → Links** or `>cleanup`.
- **[Ping, traceroute and DNS records](/launcher/network/):** `ping`, `trace` and `dns` in the launcher, and as three widgets. They are built into the program (no helper programs), so output looks the same on Windows, Linux and macOS.
- **[Open a file in tool widgets](/widgets/tool-widgets/):** JSON, YAML/TOML, CSV, URL, HTML and the text diff take a file by button or drag and drop. Hash and Base64 work on the file's raw bytes. Files are read in your browser and never uploaded.
- **[Several countdowns in one widget](/widgets/countdown/):** as a list or small tiles, reorderable, optionally sorted by date. Existing countdowns carry over.
- **Add tile button** beside **＋ Group** above the grid.
- {{metric.web_tests}} web tests and {{metric.rust_tests}} Rust tests.

## Things you might notice

- Ping and traceroute use IPv4 for now. On Linux, ping needs permission for unprivileged ICMP; otherwise it falls back to a TCP connection time and says so. See [Docker](/getting-started/docker/).
- Link checks and network tools run from the machine running Home Screen, only when you press the button. See [Privacy and security](/guides/privacy-and-security/).
- The program is about 66 KB larger ({{metric.exe_bytes_fmt}} bytes) and still fits on a floppy disk: [Binary size](/reference/binary-size/).

## Upgrading

Nothing to do. The database file format is unchanged.
